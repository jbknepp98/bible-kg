# Bible-Project handoff (Cowork → Claude Code)

Goal: knowledge graph of every named individual in the Old and New Testaments, served from Postgres through Timebase Connect into Timebase Atlas (library `bible-people`, domain `Bible-Project`). Use the Timebase_Atlas and Timebase_Connect MCP servers wherever they expose the operation. Where they don't, use the REST API with the same Pulse token.

## Postgres model (schema `bible`)

- `person`: person_id (PK, e.g. `david_994`), first_name, family_name, display_name (unique), also_known_as, gender, place_of_birth, place_of_death, year_of_birth, year_of_death (signed int, negative = BC), *_label, manner_of_death, testament, appears_in_both_testaments, tribe, affiliations, summary_of_life, summary_source (Curated / Easton's Bible Dictionary / Generated), first_reference, verse_count, roles, primary_role
- `king`, `prophet`, `priest`, `judge`, `apostle`: role extension tables keyed by person_id
- `relationship_type` (33 types) and `relationship` (from_person_id, relationship_type, to_person_id, scripture_reference, source)
- Views per Atlas type (each person appears in exactly one, by `primary_role`): `v_atlas_person` (2,780), `v_atlas_king` (141), `v_atlas_prophet` (62), `v_atlas_priest` (34), `v_atlas_judge` (14), `v_atlas_apostle` (19), plus `v_atlas_relationship` (5,129)
- Excluded on purpose (spiritual beings / deities, per scope): god_1324, holy_spirit_7400, satan_2476, gabriel_1261, michael_2068, apollyon_2, lucifer_1832, adrammelech_103, anammelech_254, ashtoreth_341, baal_573, baal-zebub_579, chemosh_931, dagon_969, diana_1008, milcom_2084, molech_2104

Relationship counts: SiblingOf 2,330 · Begot 1,783 · HalfSiblingOf 244 · Married 105 · Served 81 · Succeeded 72 · Opposed 65 · Killed 63 · Rebuked 45 · Followed 42 · Defeated 32 · Appointed 31 · Commissioned 31 · Rescued 27 · Deceived 22 · Captured 20 · Blessed 17 · Mentored 15 · Freed 12 · Imprisoned 12 · Accompanied 12 · Sentenced 10 · Cursed 10 · Anointed 9 · Healed 8 · Baptized 7 · Exiled 5 · Betrayed 5 · WroteTo 5 · Pursued 3 · RaisedFromDead 3 · Adopted 2 · Denied 1.
Married / SiblingOf / HalfSiblingOf are symmetric and stored once per pair. 811 people have no relationships (list-only names in the source).

## Atlas library `bible-people`

Naming: entity types and properties PascalCase, relationships camelCase (matches `atlas-common`). URI prefix `urn:atlas:ontology:bible-people:`.

- Entity types: `Person`; subtypes `King`, `Prophet`, `Priest`, `Judge`, `Apostle` (parentType Person)
- Person properties (22): PersonId, FirstName, FamilyName, DisplayName, AlsoKnownAs, Gender, PlaceOfBirth, PlaceOfDeath, YearOfBirth, YearOfDeath, YearOfBirthLabel, YearOfDeathLabel, MannerOfDeath, Testament, AppearsInBothTestaments, Tribe, Affiliations, SummaryOfLife, SummarySource, FirstReference, VerseCount, Roles
- King: RoyalTitle, Kingdom, Dynasty, ReignStartYear, ReignEndYear, ReignStartLabel, ReignEndLabel, ReignLengthYears, Assessment
- Prophet: ProphetClass, BooksAuthored, MinistryStartYear, MinistryEndYear, Audience, IsTrueProphet
- Priest: PriestlyOrder, IsHighPriest, ServedAt, TenureStartYear, TenureEndYear
- Judge: JudgeOrder, TribeOfOrigin, YearsJudged, Oppressor, JudgeshipStartYear
- Apostle: ApostleGroup, PriorOccupation, CallingReference, DeathTradition
- Edge properties: ScriptureReference, RelationshipSource
- 33 relationship types (Person → Person, base `urn:atlas:vocab:RelationshipBase`, with inverse names): begot, married, siblingOf, halfSiblingOf, adopted, succeeded, anointed, appointed, commissioned, served, followed, accompanied, mentored, opposed, pursued, defeated, captured, imprisoned, exiled, sentenced, killed, betrayed, deceived, denied, freed, rescued, healed, raisedFromDead, baptized, blessed, cursed, rebuked, wroteTo

Design decision: Atlas gives an instance one type, so people with two roles are typed by their primary role (priority King > Apostle > Prophet > Judge > Priest; Aaron, Eli and Zacharias the priest are Priest). All roles are kept in `Roles`. The 10 affected: Aaron, Barnabas, Deborah, Eli, Ezekiel, Jeremiah, Melchizedek, Samuel, Zacharias (father of John), Zacharias (son of Jehoiada). Secondary-role fields (e.g. Jeremiah's priestly order) live only in Postgres.

## Atlas domain `Bible-Project` instance maps

- `structure.map.json`: `bible-root` (Folder `Bible`, the only no-map definition), `testaments` (Folders `Bible.OldTestament`, `Bible.NewTestament`), `bible-contains-testaments`, plus 6 rowset `testament-contains-<topic>` edges (regex transform on `testament` → column `T`)
- `people.map.json`: 6 rowset definitions `people`, `kings`, `prophets`, `priests`, `judges`, `apostles`. instanceId `Bible.Person.[Id]`, label `[Name]` (display_name), every property a StaticStrategy from a map column `[p.<column>]`
- `relationships.map.json`: 33 rowset definitions `rel-<type>`, source `Bible.Person.[From]`, target `Bible.Person.[To]`, instanceId `<type>-[Rid]`

## Remaining steps

1. **Start Postgres** (in this folder):
   ```bash
   docker run -d --name bible-pg --env-file bible.env -p 5433:5432 \
     -v "$PWD/initdb":/docker-entrypoint-initdb.d:ro \
     -v bible-pg-data:/var/lib/postgresql/data postgres:16
   ```
   Check: `docker exec bible-pg psql -U bible_admin -d bible -c "select count(*) from bible.person"` → 3050.
2. **Enable the Connect source**: `PATCH https://localhost:4562/api/connectors/con_445bf6/enabled {"enabled":true}`. Confirm with Connect MCP `get_connector` (id `con_445bf6`) that it is Running and advertises the 7 topics. Optional: `POST /api/connectors/con_445bf6/preview {"bindingPath":"bible-pg/Kings"}`.
3. **Re-validate Atlas**: `GET https://localhost:4552/api/v1/branches/main/domains/Bible-Project/validation` should drop to 0 errors. Fix anything left.
4. **Compile the domain**: use the MCP tool if Timebase_Atlas exposes one; otherwise `PUT /api/v1/branches/main/domains/Bible-Project/world`.
5. **Verify with `ExecuteCypherQuery`** (domain `Bible-Project`). Expected:
   - Person-family nodes 3,050 (Person 2,780 · King 141 · Prophet 62 · Priest 34 · Judge 14 · Apostle 19), Folders 3
   - Relationship edges 5,129 (counts per type above) plus 3,052 `contains`
   - Spot checks: Jacob (`israel_682`) begot 13 children; David (`david_994`) married 8; `jesus_905` appointed/commissioned the Twelve; the Judah kings run Rehoboam → Zedekiah via `succeeded`
6. **Security**: rotate the `Claude` Pulse client secret (it was pasted in a chat) and update the MCP configs.
